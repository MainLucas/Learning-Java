### Classes e Objetos: Conceito.

Uma **classe** é como um **molde** ou **modelo** que define as **características (atributos)** e **comportamentos (métodos)** de algo.  
Ela **não é o objeto em si**, mas sim a **definição** de como os objetos daquele tipo devem ser.

> 🧠 **Pensa em uma receita de bolo**: ela explica os ingredientes (*atributos*) e o modo de preparo (*métodos*), mas ainda **não é o bolo**.
---

Um **objeto** é uma **instância de uma classe**.  
É como **criar algo a partir da receita**: agora você tem um **bolo real**, com sabor, cheiro, tamanho — algo **concreto e utilizável**.

> 🧠 **Se a classe é a receita, o objeto é o bolo pronto.**

### O que vimos na prática.
